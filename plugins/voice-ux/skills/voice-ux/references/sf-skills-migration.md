# Finding Agentforce Generate

Use the installed Salesforce plugin when available. In Codex it provides both
`voice-ux` and `agentforce-generate` in the same bundle. Use the resolved skill
path rather than guessing where the plugin was cached.

SF Pi users can also use the managed effective copy at
`~/.pi/agent/sf-skills/effective/skills/agentforce-generate/SKILL.md`.
The source clone is not a replacement for the effective tree. A manual-only
managed skill still satisfies the dependency; do not install a duplicate.
