# Degree of Personification Migration

Use this only when reading a Persona created with the retired taxonomy. New Personas use **Not personal → Individuated → Anthropomorphic**.

## Starting mappings

- `Talking System` → `Not personal`
- `Familiar Thing` → `Individuated`
- `Personal Assistant` → `Anthropomorphic`

These are migration starting points, not automatic equivalences. Re-evaluate the observable cues:

| Decision | Not personal | Individuated | Anthropomorphic |
|---|---|---|---|
| Separate user-facing identity | No | Descriptive agent label | Person-like individual identity |
| Singular self-reference | Heavily suppressed | Functional ownership only | Natural and consistent |
| Personal opinions | No | No | May be deliberately designed |

A retired high-personification Persona that merely used a name and first person but prohibited personal opinions usually maps more accurately to **Individuated**, not Anthropomorphic. Record the exception rather than averaging conflicting cues.

Keep Organizational “we” and Human experiences or feelings as separate decisions; neither automatically changes the degree.
