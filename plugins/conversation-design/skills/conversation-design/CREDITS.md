# Credits

This skill was authored for the Agentic Experience Specialist (AXS) toolchain in the `Agentic-Experience-Hub-Skill` repository. The framework synthesises ideas from the Conversation Design Institute (CDI), Google's Conversation Design Guidelines, Cathy Pearl's *Designing Voice User Interfaces* (O'Reilly), Nielsen Norman Group, and Salesforce's published Agentforce architecture patterns. See `references/framework-grounding.md` for the full lineage and `references/conversation-design-principles.md` for the principle rubric the skill cites against.
