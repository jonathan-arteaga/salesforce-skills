- Salesforce org with Agentforce + Omni-Channel configured
- User permissions: Omni-Channel Supervisor or equivalent
- SF CLI installed and authenticated

## Quick Start

### Markdown Format

1. Read `TEST_SCENARIOS.md` to understand all scenarios
2. Read `TEST_EXECUTION_GUIDE.md` for execution instructions
3. Pick a scenario and follow its test steps. For example:

**Scenario R1: Agents Available → Successful Routing**
1. Set agent presence to "All - Available" in Omni-Channel widget
2. Open messaging channel and trigger escalation
3. Confirm AgentWork created in correct queue
4. Run verification query:
   ```bash
   sf data query --query "$(cat queries/verify-routing.soql)" --target-org <alias>
   ```
5. Record result in `results/TEST_LOG.md`

### HTML Format

1. Double-click `test-dashboard.html` to open in your browser
2. Use the filter bar to focus on specific priorities or categories
3. Expand a scenario card to see full test steps and SOQL queries
4. Mark pass/fail via the dropdown — results auto-save in your browser
5. Click "Export TEST_LOG.md" when testing is complete

## Common Issues

### Agent Presence Not Updating
- Refresh Omni-Channel widget
- Check user has correct permissions
- Verify ServicePresenceStatus configuration

### Escalation Not Triggering
- Check utterance matches escalation trigger
- Verify agent definition has escalation configured
- Review agent file for escalation subagent logic

### Queries Return No Results
- Verify correct org alias
- Check date/time filters in queries
- Ensure test actually created records
